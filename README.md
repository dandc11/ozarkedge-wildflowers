## Ozarkedge Wildflowers

This is the source for the Ozarkedge Wildflowers site built with Next.js and Sanity.io CMS.

- Framework: Next.js (App Router)
- CMS: Sanity.io
- Styling: PostCSS + custom CSS (no Tailwind)
